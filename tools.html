Claude Code tool guide

Every entry from the "Claude Code Resource Bible" cheat sheet, inspected one by one. Each card is stamped with what we found: the link works as described, the link was broken and is now fixed, or the cheat sheet described the tool wrong. Star the ones you want in your stack.

Cheat sheet bloopers

  • 16 of the 55 links were dead or wouldn't load. Eight point to the same GitHub account, micholasoxford, which has no such repos. Each now points to the official or best-known working equivalent, with the original shown crossed out on its card.
  • 8 entries describe the tool wrong. "Loop" is a screen-recording video editor, not a task runner. "Clawd Cursor" has nothing to do with Cursor. "Superpowers" isn't browser or LinkedIn tooling.
  • The numbering skips #20 and uses #29 twice. Dokploy is filed here as #19.
  • Star counts on the cheat sheet couldn't be confirmed, so they're left off.
